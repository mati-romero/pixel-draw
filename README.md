# Pixel Draw

Aplicación web para crear dibujos digitales mediante píxeles, con una interfaz sencilla e intuitiva que permite experimentar con el arte pixelado.

## Descripción

Pixel Draw es un proyecto de desarrollo web enfocado en la creación de una herramienta de dibujo digital. Su objetivo es ofrecer una experiencia accesible para crear ilustraciones pixel art directamente desde el navegador.

El proyecto permite poner en práctica conocimientos de desarrollo frontend, manipulación de elementos gráficos e interacción con el usuario.

## Características

- Interfaz visual orientada al dibujo digital.
- Experiencia de uso sencilla e intuitiva.
- Creación de ilustraciones con estilo pixel art.
- Proyecto web ejecutable desde un navegador.

## Tecnologías utilizadas

- HTML5 para la estructura de la aplicación.
- CSS3 para los estilos y el diseño de la interfaz.
- JavaScript para la lógica y las interacciones.

## Instalación y ejecución

1. Clonar el repositorio:

   ```bash
   git clone https://github.com/mati-romero/pixel-draw.git
   ```

2. Ingresar al directorio:

   ```bash
   cd pixel-draw
   ```

3. Abrir el archivo `index.html` en un navegador web.

Si el proyecto utiliza dependencias o herramientas de desarrollo adicionales, consultar la configuración del repositorio antes de ejecutarlo.

## Objetivo del proyecto

Desarrollar una herramienta interactiva de dibujo digital y reforzar conocimientos de desarrollo frontend, diseño de interfaces y programación con JavaScript.
